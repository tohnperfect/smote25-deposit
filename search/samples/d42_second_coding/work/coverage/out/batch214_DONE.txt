Codes I was least sure of:
- R03490 eligibility (E1 vs eligible under ruling B): unchanged imbalanced-learn SMOTE after PCA/CAE feature extraction, one fraud dataset. The stated contribution is the evaluation of feature extractors (CAE vs PCA), so I coded E1 with no ruling prefix. But the abstract calls feature extraction before SMOTE "our proposed method", and Table 1 compares it with SMOTE alone. Read as an existing sampler in a learned space, it could pass ruling B (Core, N=yes).
- R00097 (SMMO) label and P/N: the M-SMOTE formula as printed (eta = m + r(m - A), A = mean of n neighbours) extrapolates beyond the seed, away from the neighbour mean. I kept it Core with P=yes. N=yes rests on an undefined "weighted distance". S=yes: seeds are minority points misclassified by a bagged LWLR ensemble.
- R00022 (Chawla et al. wrapper) L: A=yes (the SMOTE amount is set by a greedy wrapper search with inner 5-fold CV). L=yes because the generator re-runs inside a search with the classifier in the loop (by analogy with "evolutionary search over generated sets"). The final SMOTE runs once before training, so L=no is defensible. vs_smote=no: plain SMOTE at a fixed amount is never a competitor. FP rate coded as specificity. Protocol cv (KDD-99 uses a provided split).
- R00004 (SMOTEBoost) S=yes vs A: seeds are sampled from the boosting distribution Dt, which I coded as S only. inside_folds=nr: nothing is stated, although SMOTE inside boosting is in-training by construction. tuning=default: N=100-500, all reported.
- R06485 (HySM_BT) all six decision points no: the chain is SMOTE then bootstrap resampling of each class to 40-60% of the majority size. It passes ruling B (presented, compared with SMOTE and bootstrap alone) but changes nothing inside the generator. inside_folds=before-split is inferred from the resampled counts (e.g. 1830 = 3 x 610, the full-data majority). tuning=test: no validation set, and the best setting/classifier is headlined from the 70/30 test split. class=M (OVA used only for classification).
- R01801 (CBSMOTE): the text is partly font-shifted (+29); I decoded it and digits are lost. N=no although SMOTE runs on the SUSPENDING subset (the partner pool may shrink). The dataset is sensor-testbed data, counted as 1 real dataset. The classifier and split are not reported (protocol, inside_folds and tuning nr).
